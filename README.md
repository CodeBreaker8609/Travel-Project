Discover Kyoto 🌸
A simple HTML webpage showcasing the beauty and culture of Kyoto, Japan. The page highlights top tourist destinations and a sample 3-day itinerary for travelers.

📸 Project Overview
This static webpage includes:

A header introducing Kyoto.

A section showcasing Top Tourist Locations with images.

A 3-Day Itinerary in table format.

A footer with a helpful travel resource link.

🧰 Technologies Used
HTML5
Basic CSS (if added in the future)

 Notes
This is a beginner-friendly project to practice HTML structure, image embedding, and basic table usage.
Future enhancements could include responsive design, CSS styling, and interactive features.
